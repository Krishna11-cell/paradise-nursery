# Paradise Nursery
Responsive React + Vite + Redux Toolkit plant shop.

## Run
1. Install Node.js LTS.
2. Extract this project.
3. Run `npm install`
4. Run `npm run dev`

Features: landing page, About Us, 18 plants across three categories, Add to Cart, dynamic cart count, Redux reducers addItem/removeItem/updateQuantity, quantity controls, remove item, subtotal, checkout placeholder, continue shopping.

Main rubric files:
- `src/App.jsx`
- `src/App.css`
- `src/components/AboutUs.jsx`
- `src/components/ProductList.jsx`
- `src/components/CartItem.jsx`
- `src/features/CartSlice.js`
